개인정보처리방침

시행일: 2026년 10월 30일

1. 사용하는 정보

달력 위젯은 사용자가 허락한 경우에만 Google 계정의 캘린더 목록과 일정(제목, 시간, 장소, 메모)을 Google Calendar API로 읽고, 사용자가 위젯에서 만든 일정을 추가·수정·삭제합니다.

2. 저장과 전송

모든 정보는 사용자의 PC 안에서만 처리됩니다. 일정 데이터는 개발자나 제3자의 서버로 전송·저장되지 않으며, 로그인 토큰은 사용자 PC에 Windows 계정 암호화로 저장됩니다. 위젯은 Google 서버와만 통신합니다.

3. 제3자 제공

어떤 정보도 판매하거나 제3자에게 제공하지 않으며, 광고나 분석 목적으로 사용하지 않습니다.

4. Google API 서비스 사용자 데이터 정책

Google API로 받은 정보의 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

5. 연결 해제와 삭제

위젯 설정의 "연결 해제"를 누르거나 Google 계정의 서드파티 액세스에서 권한을 취소할 수 있습니다. PC의 %APPDATA%\CalendarWidget 폴더를 지우면 저장된 정보가 모두 삭제됩니다.

English summary: This app only accesses your Google Calendar data on your own PC to display and edit your events. No data is sent to or stored by the developer or any third party. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
