📅 달력 위젯 (Calendar Widget)

윈도우 바탕화면에 띄워 두는 개인용 반투명 달력 위젯입니다. 사용자의 구글 캘린더 일정을 월간·주간·목록으로 보여주고, 위젯에서 만든 일정을 구글 캘린더에 저장합니다.

A personal Windows desktop calendar widget that shows the user's Google Calendar events and lets the user create, edit and delete events.
